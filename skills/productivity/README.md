# Productivity skills

Skills for daily non-code workflows.

## Model-invoked

- [bookmark-corpus](./bookmark-corpus/SKILL.md) — screens a week of bookmarks into one card per
  distinct thing (origin link, the retellable detail, click payoff, counterpoint), so a writer can
  pick without opening links.
- [brain-dump-post](./brain-dump-post/SKILL.md) — chooses from that corpus by what a reader gets
  when they click, and writes a plain, lowercase, link-first roundup for coworkers.
